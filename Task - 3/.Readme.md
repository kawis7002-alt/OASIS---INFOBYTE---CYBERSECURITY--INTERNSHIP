# TASK 3 – Password Strength Analysis

## Objective
To evaluate password strength, understand secure password practices, and identify methods for creating strong passwords.

## Tools Used
- Online Password Strength Checker
- Web Browser
- GitHub

## Procedure
1. Opened an online password strength checker.
2. Tested different passwords.
3. Analysed password complexity and security ratings.
4. Compared weak and strong passwords.
5. Recorded the observations.
6. Captured screenshots.
7. Uploaded the documentation to GitHub.

## Conclusion
The analysis showed that long, unique, and complex passwords provide better protection against cyber attacks.
