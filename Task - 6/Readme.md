# TASK 6 – Port Scanning using Nmap

## Objective
To perform a port scan using Nmap and identify open ports and running services on a target system.

## Tools Used
- Nmap
- Command Prompt
- GitHub

## Procedure
1. Installed Nmap.
2. Opened Command Prompt.
3. Executed an Nmap scan on the target IP.
4. Observed open ports and services.
5. Analysed the scan results.
6. Captured screenshots.
7. Uploaded the documentation to GitHub.

## Conclusion
The Nmap scan successfully identified active ports and services, helping assess network security.
