# TASK 2 – Firewall Configuration

## Objective
To configure and manage the system firewall by creating firewall rules that improve network security and control incoming and outgoing traffic.

## Tools Used
- Windows Defender Firewall
- Command Prompt
- GitHub

## Procedure
1. Opened Windows Defender Firewall with Advanced Security.
2. Reviewed existing inbound and outbound rules.
3. Created a new firewall rule to allow or block a specific port.
4. Applied the firewall rule.
5. Verified that the rule was working correctly.
6. Captured screenshots of the configuration.
7. Documented the procedure and uploaded it to GitHub.

## Conclusion
The firewall was successfully configured to manage network traffic and improve system security.
