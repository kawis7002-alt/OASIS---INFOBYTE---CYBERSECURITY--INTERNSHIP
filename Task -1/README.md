# TASK 1 – Network Security Assessment

To perform a basic network security assessment by identifying devices connected to the network, discovering open ports and services, and understanding potential security risks.

## Tools Used
- Nmap
- Command Prompt
- GitHub

## Procedure
1. Installed Nmap on the Windows system.
2. Opened Command Prompt.
3. Identified the local IP address using the `ipconfig` command.
4. Ran an Nmap scan on the target IP address.
5. Observed the open ports and running services.
6. Analysed the scan results to identify possible security issues.
7. Captured screenshots of the scan results.
8. Documented the findings and uploaded the task to GitHub.

## Conclusion
The network security assessment was completed successfully using Nmap. The scan identified active hosts, open ports, and available services, providing a basic understanding of the network's security posture.
